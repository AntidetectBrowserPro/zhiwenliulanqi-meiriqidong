# 免费指纹浏览器会限制每天打开次数吗？

是否限制每天打开次数，要看具体套餐中的“启动”字段。「指纹浏览器」工作台对已经运行的环境提供「定位」，需要找回原窗口时可以直接定位，避免反复关闭再打开。
[官网操作说明](https://zwbrowser.com/help/desktop/find-environment/)

![工作台中的环境名称与窗口操作](https://zwbrowser.com/images/desktop-guide-open-list-light.webp)

## 演练一次繁忙日

假设有四家店，每家早晚各开一次，是八次打开；中午只是切回仍在运行的窗口，就在记录里另列“定位”。产品怎样计算计费次数，以它自己的用量页为准。可以先用测试环境做一次操作，观察计数是否变化。

## 注意别读错字段

“每天最多新建”回答一天能创建多少份新配置；“环境上限”回答能保留几份。看到这两个数字仍不能推导启动次数。套餐页没写时，向官方支持描述你的操作，再核对用量记录。
